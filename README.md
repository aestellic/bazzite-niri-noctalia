# Bazzite

This is a custom image of Bazzite which uses Niri as the wayland compositor and Noctalia Shell as the desktop shell.

## List of installed packages:
 - Niri (wayland compositor)
    - Mako (notification daemon)
    - xdg-desktop-portal-gnome and xdg-desktop-portal-gtk
    - Gnome Keyring (secrets portal)
    - xwayland-satellite (X11 proxy)
    - Plasma Polkit Agent (graphical sudo)
 - Noctalia Shell (desktop shell)
    - Cliphist (clipboard history)
    - DDCUtil (brightness control)
 - Ghostty (terminal)
 - Dolphin (file manager)
 - Ark (archive manager)
    - Unrar
 - Gnome Desktop Manager
 - Gnome Virtual File System
 - Librewolf (browser)
